# AI Workplace Productivity Assistant

## Project Overview

AI Workplace Productivity Assistant is a modern web application designed to help professionals streamline daily work through Artificial Intelligence. The platform combines multiple productivity tools into a single dashboard, enabling users to generate emails, summarize meetings, create task plans, conduct research, and interact with an AI assistant.

The application follows responsible AI practices by ensuring all AI-generated content remains editable and includes transparency notices encouraging human review.

---

## Features

### Smart Email Generator

* Generate professional emails instantly
* Multiple communication tones
* Editable output
* Copy and download options

### Meeting Notes Summarizer

* Summarize meeting transcripts
* Extract action items and key decisions
* Editable summaries

### AI Task Planner

* Convert goals into actionable plans
* Priority-based task organization
* Timeline recommendations

### AI Research Assistant

* Generate research reports
* Identify opportunities and risks
* Structured recommendations

### AI Chatbot

* Conversational AI interface
* Workplace productivity assistance
* Chat history support

### Dashboard

* Activity overview
* Productivity statistics
* Quick action shortcuts

## Setup Instructions

### 1. Clone Repository

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to Project

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file:

```env
OPENAI_API_KEY=your_api_key
```

### 5. Start Development Server

```bash
npm run dev
```

### 6. Build for Production

```bash
npm run build
```
